Three Pillars

三件事，合成一个学习操作系统

市面上没有把"自动排程 + 游戏化激励 + 数据复盘"三合一的产品。复利 把这三件分开做扎实的事，接成一条闭环。

01 / 排程

说一句话，全天自动重排

你只给目标、截止时间和预估时长，确定性贪心引擎就把任务铺进日历。一句"明天下午有事"，触发重排——主线保住截止，支线见缝插针。手动拖动的块标记为锁定，AI 绝不乱动。

工程视角 · 排程骨架是纯 Kotlin 确定性算法（贪心 + 优先级队列），断网照常工作；LLM 只做自然语言解析与学习路线建议，从不在核心计算里临场发挥。

专注就是挖矿，CI币就是工资

The CI Economy

CI币经济：一套你看得懂的规则

设计原则只有一条——CI币只能靠专注时间产出。日均可挣 200–300 CI币，月产约 6,000–9,000。规则写死、锚定现实，所以你永远知道"一小时专注 ≈ 三块钱工资"。

CI Import · v1

把计划一次搬进来：JSON 固定导入

把领域、主线 / 支线任务线和具体日程写成一份 JSON，在 App 里一键导入。格式刻意宽容——贴聊天 AI 的原始回复（带 markdown 围栏和闲话）也能解析；先校验再落库，错误逐条列出，绝不静默吞掉。

字段速查
  • domain · name + 恰好 6 个头衔（或不填，用通用兜底表）
  • quests[] · type MAIN / SIDE、title、deadline（仅主线）、chapters[]
  • tasks[] · title、date yyyy-MM-dd、start/end HH:mm、difficulty、quest（引用任务线标题）、locked
EASY ×0.8 NORMAL ×1.0 HARD ×1.3 EPIC ×1.6

技术底气

单人项目，工程上刻意"离线优先 + 可单测"——断网不降级，逻辑可验证。
Kotlin + Jetpack Compose Room · 本地 SQLite Vico · 图表 Glance · 小组件 MediaPipe · 本地模型 前台服务 · 计时保活 MVVM + Repository Keystore · 密钥加密
确定性排程引擎
纯 Kotlin 贪心 + 优先级队列，无状态可单测；LLM 仅做解析与建议。
本地模型兜底
MediaPipe 跑 Qwen3-4B / Gemma3-4B int4，断网也能自然语言调整。
数据全在本地
支持 JSON / CSV 导出备份；复盘与统计永不依赖云端。
路由表可控
每类任务手动指定 本地 / 某个 API / 关闭，关闭即降级不报错。
